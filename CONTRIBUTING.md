# Contributing

1. Open an issue describing the DV problem, affected domain, and expected artifact.
2. Create or edit only the canonical `skills/` source. `.claude/skills/` and `.agents/skills/` are generated adapter trees; never edit them by hand, because the next synchronization replaces them.
3. Run `python scripts/sync_adapters.py --check` first. It reports whether the adapter trees differ from `skills/` (exit 1 on drift, exit 0 on parity) and modifies nothing. Then run `python scripts/sync_adapters.py`. **This replaces `.claude/skills/` and `.agents/skills/` with byte-identical copies of `skills/`; any file in those two directories that is not in `skills/` is deleted.** Commit or stash anything you want to keep before running it; adapter edits belong in `skills/` anyway. Exit codes: `0` synchronized or already in parity; `1` drift (`--check` only); `2` usage error; `3` unsafe path state (a link or junction in the path chain or inside `skills/`, a target that is not a directory, or a path outside the repository), nothing modified; `4` `skills/` missing or empty, nothing modified; `5` I/O failure while staging or swapping, the previous tree left in place or restored; `6` leftover `.skills.staged-*` or `.skills.old-*` directories under `.claude/` or `.agents/` from an interrupted run, inspect and remove them by hand, nothing modified. Details in [docs/scripts.md](docs/scripts.md).
4. Run `python scripts/validate.py` and `python -m unittest discover -s tests -v`; both must exit 0. The validator prints `Validation OK: <n> skills, <m> schemas, adapter parity confirmed.` on success and one `ERROR:` line per problem, with exit 1, otherwise.
5. Submit a focused pull request with threat, license, and methodology implications.

Skills must be vendor-neutral, evidence-gated, non-destructive by default, and free of employer-confidential or copied proprietary material. `scripts/validate.py` checks each `skills/<name>/SKILL.md` for: YAML frontmatter whose `name` equals the directory name, with no duplicate names across skills; the exact headings `## Purpose`, `## Inputs`, `## Workflow`, `## Checks`, `## Deliverables`, `## Evidence Gate`, `## Stop Conditions`, and `## Safety` (case-sensitive substring match); and at least 1800 characters of text. It also parses every `schemas/*.json` file and the two `templates/*.json` files, runs `sync_adapters.py --check`, and applies a small regex blocklist of unsafe command patterns to `scripts/*` and `skills/*/SKILL.md` (the `unsafe` list in `scripts/validate.py` is the authoritative set). Other frontmatter fields (`description`, `version`) are not checked.
